# Code of Conduct for Neo Angband Projects

Effective date: 2026-08-23.

## Scope

This Code is intended for adoption in the `neo-angband` repository and the six `neo-angband-mod-*` repositories. It applies to issues, pull requests, discussions, review comments, documentation contributions, and other project interactions. It also applies to Neo Angband discussions in the RPGM Tools Discord.

GitHub and Discord maintain their own platform rules. This Code supplements, and does not replace, those rules.

## Expected conduct

Participants are expected to communicate in good faith, discuss technical disagreements on their merits, respect differing experience levels, and keep feedback relevant to the project. Reports, reviews, and corrections should identify observable behavior, evidence, or a proposed improvement where possible.

## Unacceptable conduct

The following conduct is not acceptable in project spaces:

- Harassment, intimidation, threats, stalking, or repeated unwanted contact.
- Discrimination, slurs, hateful conduct, or personal attacks directed at a person or group.
- Sexual language or imagery that is not relevant to the project.
- Publishing another person's private or identifying information without permission.
- Deliberate disruption, spam, impersonation, bad-faith reporting, or attempts to compromise project systems or community spaces.
- Retaliation against a person for making a good-faith report or participating in a review.

Disagreement about game design, mod behavior, licensing, documentation, or implementation is not misconduct by itself. Persistent personal attacks, threats, or disruption are not made acceptable by a technical disagreement.

## Reporting

Conduct concerns can be reported through the project's published private contact route: `strider-angband (at) rpgm.tools`. A report should include relevant links, dates, and a concise description when available. Public disclosure of a security vulnerability should follow `SECURITY.md` instead.

## Response and enforcement

A maintainer can review reported conduct and take proportionate action based on the available context. Possible responses include clarification, a request to stop, a warning, removal or editing of content where the platform permits it, closing an issue or pull request, restricting participation, referral to GitHub or Discord moderation, or removal from a project-controlled community space.

A participant may request reconsideration through the same private contact route. A reconsideration request should identify the action and relevant context. No outcome is promised.
